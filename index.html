StackDraw

Drawing Application with Stack-Based Undo

Demonstrating the LIFO principle using a Stack data structure.

Pencil: drag to draw. Line and Arrow: drag from start to end. Rectangle, Oval, Diamond, Triangle, Heart and Cross: drag from corner to corner. Circle, Star, Pentagon, Hexagon and Spiral: drag from the centre outwards.

How the Stack Works

A stack follows the LIFO (Last In, First Out) principle. In this drawing application, every drawing action is stored in a stack. When the user clicks Undo, the most recent drawing action is removed first using the pop operation. This allows the application to reverse drawing actions in the correct order.

PUSH

Adds a drawing action to the top of the stack.

POP

Removes the most recent drawing action.

PEEK

Views the action currently at the top of the stack.

isEmpty

Checks whether the stack contains any actions.

SIZE

Returns the number of actions stored in the stack.

Redo uses a second stack. Undo pops from the Undo Stack and pushes onto the Redo Stack; Redo does the opposite.
